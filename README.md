# Curtis Salley: Inventory & Operations

One-page professional site for inventory, operations, and supervisor roles.
Live: https://blkctrs-sys.github.io/curtis-salley/

- `index.html`: the page (no build step)
- `resume.html`: printable resume source; `resume.pdf` is generated from it with
  `msedge --headless --no-pdf-header-footer --print-to-pdf=resume.pdf resume.html`
- `img/`: Stockroom screenshots
